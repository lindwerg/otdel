# Дизайн и Отто

Источник: предоставленный владельцем проект `Documents/ChatGPT/Otdel`, а не ранний `Desktop/Otdel`.

Семь PNG из `apps/web/public/brand/otto/` перенесены без изменений по указанию владельца. Это оригинальный маскот проекта Отто. Названия состояний: welcome, mail, search, question, pause, success, error. PNG имеют графитовый фон; прозрачность не заявляется. Не перекрашивать CSS-фильтрами.

Палитра извлечена из `apps/web/src/app/globals.css`: фон #101213, поверхность #191b1c, приподнятая #222424, текст #ede9df, вторичный #aeafa6, линия #343733, золото #cbb578, hover #dfc991, фокус #e9d99f. Шрифт Manrope Variable. Старые бизнес-правила, ключи, база и зависимости исполнения не переносятся.
